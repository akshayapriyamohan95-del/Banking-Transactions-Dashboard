# Banking Transactions Dashboard 📊

## 📌 Project Overview
This project analyzes banking transaction data using Microsoft Excel to identify transaction patterns, monitor transaction status, and compare performance across branches and transaction channels.

The goal is to transform raw transaction data into a clear, interactive dashboard that supports data-driven decision-making.

## 🎯 Project Objectives
- Analyze banking transactions and their status.
- Track key performance indicators (KPIs).
- Understand monthly transaction trends.
- Compare transaction volumes across branches.
- Analyze transaction channels.
- Present key findings through an Excel dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Excel formulas and functions
- PivotTables
- Charts and data visualization
- Conditional formatting
- Dashboard design

## 📂 Dataset
- **Dataset:** Banking Transactions
- **Number of records:** 300 transactions
- **Primary identifier:** Transaction_ID

The dataset is used for practice and analytical purposes.

## 📈 Key Performance Indicators (KPIs)
The dashboard is designed to display:
- Total Transactions
- Successful Transactions
- Failed Transactions
- Total Transaction Amount

*Final KPI definitions and calculations will be documented based on the completed workbook.*

## 📊 Dashboard Visualizations
The dashboard includes:
1. Transaction Status Analysis
2. Monthly Transaction Trends
3. Branch-wise Transaction Analysis
4. Transaction Channel Analysis
